TIYUHM App Map

TIYUHM reads your GitHub commits, has a local AI model judge which ones matter, and turns those into a resume page and PDF. It refreshes itself when you ship new work.

Main pieces

  • Pages (pages/): the gate, the setup form, the resume, and a print view for the PDF.
  • Server routes (server/api/): thin endpoints the pages call.
  • Pipeline (server/utils/pipeline.ts): the kernel. Triage, bullet writing, summary.
  • AI adapter (server/utils/ai/): talks to Ollama.
  • Storage (data/*.json via server/utils/store.ts): saved verdicts and resume.

One action: opening your resume

Reference route (a recap, not a toured walkthrough)

  1. pages/resume.vue: search useFetch<Resume | null>('/api/resume'). The page asks for the saved resume.
  2. server/api/resume/index.get.ts: a one-liner that calls readJson on resume.json.
  3. components/ResumeBody.vue: search v-for="g in resume.experience". This draws each owner's group, including the "Vanquished" label.
Where the data comes from

generateResume and refreshResume in server/utils/pipeline.ts build the experience groups and save them with writeJson('resume.json', …). They are called by generate.post.ts and refresh.post.ts.

To change this, start here

  • Wording or labels on the resume: components/ResumeBody.vue. Example kept edit: Holding became Vanquished (search class="kicker holding").
  • Colors and fonts: assets/css/theme.css (variables such as --paper, --accent, --font-gothic).
  • What counts as a meaningful commit: Pass 1 prompt in server/utils/prompts.ts, used by triageCommits in pipeline.ts.
  • The PDF: pages/print/resume.vue and server/api/pdf/index.get.ts.

A practice to reuse

Decision: the theme lives only in the presentation layer (ResumeBody.vue, theme.css). The pipeline only produces data.

Evidence: relabeling "Holding" to "Vanquished" touched one template line, and nothing in pipeline.ts had to change.

Next project: when you ask an agent for a restyle, name that boundary in the prompt ("change only the templates and CSS, leave the data logic alone"). Your style then stays your own, and the logic stays safe.

Run it again

npm install, copy .env.example to .env, make sure Ollama is running, then npm run dev and open http://localhost:3000. See README.md for tokens and the Chrome install for PDFs.
